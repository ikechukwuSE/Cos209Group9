# NON-FUNCTIONAL REQUIRMENT
PERFORMANCE
The system should load pages within 4 seconds under normal network conditions.
Menu browsing and cart updates should respond quickly.
The system should handle multiple users accessing the platform simultaneously.

SECURITY
User passwords must be securely hashed.
Customer information must be protected against unauthorised access.
Only authorised administrators(vendors)  should access the admin dashboard.
User sessions should be managed securely.

RESPONSIVENESS
The system should work on mobile phones, tablets and desktop computers.
The interface should automatically adjust to different screen sizes.

AVAILABILITY
The system should be accessible whenever the restaurant is accepting orders.
Scheduled maintenance should be communicated where necessary.

RELIABILITY
The system should accurately store customer orders.
Order information should not be lost during normal system operations.
The system should prevent invalid or incomplete orders from being submitted.
Order statuses should remain consistent between the customer and administrator dashboards.
